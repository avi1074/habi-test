# Análisis a negocio

Entregue aquí el hallazgo para un usuario NO técnico: una historia con recomendación
accionable. **Lleve el análisis hasta donde considere que aporta valor.**

Formato libre según lo que su caso amerite:
- reporte escrito (Markdown/PDF/Word)
- dashboard
- notebook analizado
- presentación en slides
- un modelo (p. ej. estimación de precio)

Sustente el alcance que eligió: por qué llegó hasta ahí y no más (o menos).
